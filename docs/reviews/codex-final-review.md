1. **Medium — Shutdown can abandon cleanup.** [backend.dart:132](/mnt/Data/Projects/maprisma-playground/flutter_app/lib/backend.dart:132), [service.dart:409](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/service.dart:409), [my_application.cc:193](/mnt/Data/Projects/maprisma-playground/flutter_app/linux/runner/my_application.cc:193).  
   The backend kills the core after four seconds without its acknowledgement. Core disposal can wait ten seconds for `systemctl stop` before reaching `runner.dispose()`. Native close/SIGTERM also quits unconditionally after eight seconds. If synchronous media processing prevents the core handling cancellation, separately sessioned children can survive application exit. **Fix:** keep process-group ownership outside the worker isolate, kill/reap those groups on the fallback path, and acknowledge close only after cleanup. Test native close and SIGTERM with a stalled core and slow service stop.

2. **Medium — Animated images can bypass the intended pixel budget.** [pictures.dart:150](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/pictures.dart:150).  
   Frame counting examines only the first MiB, using byte-pattern counts for GIF/WebP; `decodeImage(bytes)` subsequently decodes the complete animation. Frames after that prefix escape the application’s aggregate limit. The installed image decoder has a larger default budget, so this can still allocate hundreds of megabytes and block cancellation. **Fix:** decode only frame zero for this feature, set an explicit decoder pixel budget, and validate actual format structures rather than counting byte patterns.

3. **Medium — Untrusted video descriptions can monopolize the core.** [chess_video.dart:102](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/chess_video.dart:102).  
   For every occurrence of `1.`, `movesInText` copies and splits the entire remaining suffix. Repeated game-start markers produce quadratic allocation/work. The original description reaches this parser before the later 20,000-character agent-prompt limit. Processing is synchronous, so cancellation cannot interrupt it. **Fix:** bound description length before parsing, tokenize once, cap candidate starts and moves, and make long parsing interruptible.

4. **Medium — Settings still use race-prone filesystem operations.** [settings.dart:87](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/settings.dart:87), [settings.dart:139](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/settings.dart:139).  
   The no-symlink check and size check precede a separate pathname read. Writing exclusively creates a temporary file, closes it, then reopens its pathname for writing. If another process can modify the directory, it can substitute a link or FIFO between operations. Existing directories are not validated as private. **Fix:** use the existing descriptor-based private-file helpers, validate directory ownership/permissions, and retain the descriptor through writing and publication.

5. **Medium — Download publication does not fully close pathname races.** [private_files.dart:210](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/private_files.dart:210).  
   `publish` checks the staging pathname’s inode, then separately renames that pathname. A process able to modify its parent can replace it between those operations, publishing bytes other than those hashed. `O_NOFOLLOW` also protects only the final component; download parent directories are not consistently validated. **Fix:** use validated, non-writable parent directory descriptors and descriptor-relative operations; stage in a private directory whose entries cannot be replaced by another account.

6. **Medium — Listener ownership is checked before connection, leaving a substitution window.** [netfetch.dart:34](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/netfetch.dart:34).  
   `/proc` ownership is checked before `openUrl`. If the legitimate server exits between those steps, another account can bind the port and receive the prompt or image. Proxy and redirect protections are present, but do not prevent this race. **Fix:** establish the connection, verify ownership of its exact server-side socket before sending HTTP data, and apply the same rule to `LocalHold` connections.

7. **Medium — Non-capturing promotion fails to reset the fifty-move counter.** [chess_rules.dart:369](/mnt/Data/Projects/maprisma-playground/packages/maprisma_playground_core/lib/src/chess_rules.dart:369).  
   `piece` has already become the promoted queen/rook/bishop/knight when the pawn test runs. A quiet promotion increments `halfmove`, potentially causing a false fifty-move draw. **Fix:** retain whether the original moving piece was a pawn and use that to reset the counter; add a quiet-promotion regression case.
